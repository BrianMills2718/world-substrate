# Connect the chat to completed runs and their evidence

## Why

The existing example action fills the composer with sample text. A visitor looking for a result has to leave the chat and find a different viewer. Opening a native run shows a map and a story, but the records that explain a round live deeper in Advanced.

## What Changes

Give the existing composer a direct route to the completed coordination example. Connect Simple run results to recorded evidence. Keep Advanced controls on their existing runtime paths.

## Impact

The canonical World Builder page, its static assets and its local preview server change. Source: Brian's November 27 goal, continuing docs/goals/unified-world-ux.md.
