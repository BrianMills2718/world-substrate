📡 Information overlay

Adds source, recipient, channel, delivery and provenance to communication already happening in the world. Turning it off does not make conversations disappear.

⛓ Causal trace

Highlights retained facts, evaluations and committed events that are ancestors of the selected consequence. A conversation appears here only when it belongs in that retained lineage.

📦 Resource overlay

Shows stocks, shortages, reservations and actual transfers over the places and actors that own or consume them.

🔎 Analytic plugin

Waltzman is one detachable interpretation of retained evidence—not part of every world's ontology. Other domains can install other lenses.

Prototype behavior is illustrative. In the intended architecture, world geometry, movement, conversations, state changes and event ancestry are projected from canonical World Substrate state and trace evidence; renderer state never writes back into simulation truth.
