The decision asked of you

Approve the first slice below: in any World Builder world, a person can start a task that takes several rounds; it fails or succeeds part-way from what changed in between; and the person finds out only from what they can see, not from a message saying "refused".

If you do not answer, nothing is built: the goal ends with this page and the fixes already merged.

5. The first slice (what gets built after a yes)

  1. Build check. Copy attempt_findings into the service's rules checks; a finding is fed into the existing one rules retry, the same way test-run failures are. No new AI call.
  2. Memory wording. For an accepted start, the person's memory says what they started, not whether it will work. Rule-of-the-game refusals keep their reason. Every later round they see the fields they can observe, plus "you expected: …" from their own earlier attempt while it is underway.
  3. Records. Each run-log round gets underway: person, action, started event id, expected effect, and when it ends, the ending event id and whether it failed or finished. The trace-read check then asks every read-through to name them.
  4. Page. The round picture gets an "underway" strip (blue while underway, orange when it fails, with words).
  5. Proof. Tests with no AI spend on the truck world and a saved people world; then one live owner-allowance run of Waltzman's scenario, read in full, that shows a part-way failure or success learned by observation. If the run shows none, that is reported, not rerun.

Out of scope: rules written mid-run, a scheduler, anything specific to Waltzman's text.

6. Risks

  • People may repeat a doomed task because nobody tells them. That is the point, but it can make runs look stuck. The "you expected" line is the guard; the read-through checks whether they notice.
  • The rules writer may still gate starts on stock. The build check catches it, but the single retry may not fix it; then the build says so plainly.
  • A world may have no long task at all. Waltzman's text has meetings, deliveries and deployment; if the live world builds none, the run is reported as "no attempt took more than one round".
