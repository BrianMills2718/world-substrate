# UI survey for the World Builder page (2026-11-17)

Source: Brian, 2026-11-17: "have you actually compared this ui to other uis? including previous versions related to my own waltzman code". This note is the survey the unified-world-ux plan cited as "the survey notes" but never committed ([plan](../plans/unified-world-ux-spec.md)). The comparison with the earlier Waltzman UIs is in [ui-comparison-waltzman-20261117.md](ui-comparison-waltzman-20261117.md).

Method: a research agent fetched each page on 2026-11-17. "Inference" marks the agent's judgement, not something the page says. It did not look at colour or accessibility on any page, so every colorblind point is inference. Could not read: ChatGPT canvas (403) and AnyLogic (403); Lovable, v0 and Concordia were only partly readable.

| Program (page read) | Adopt or adapt | Reject |
| --- | --- | --- |
| Lovable (docs.lovable.dev/introduction/welcome) | chat, preview and version history in one project; chat sends work to the project only when something needs building | could not read history or remix |
| v0 (v0.app/docs, first 100k characters) | every applied edit is a visible version you can diff, iterate on or revert; a plain-words "what changed" per draft | sandbox preview; no forking found |
| Replit Agent (docs.replit.com/replitai/agent) | a plan you review and revise before anything is built; automatic checkpoints with rollback | the Free/Power/Max/Auto mode popover |
| Generative Agents / Smallville (github.com/joonspk-research/generative_agents) | a new run is a fork of a named saved run; replay takes a start step; a speed control | terminal-only control; identical sprites in debug replay (colour/shape-only identity is a risk, inference) |
| AI Town (github.com/a16z-infra/ai-town) | a visible freeze button; auto-pause on inactivity | nothing on replay or branching; map edited in Tiled |
| Concordia (github.com/google-deepmind/concordia) | a referee that turns stated intentions into outcomes (our judge rulings); templates (prefabs) as starter worlds | visualization not confirmed |
| NetLogo (docs.netlogo.org/interface.html) | export the run data and the picture | Interface/Info/Code tabs and command centre |
| Machinations (machinations.io) | play step by step; a public gallery of remixable models; compare many futures (adapt: state the result in words) | |
| Git Graph (marketplace.visualstudio.com, mhutchie.git-graph) | pick two nodes to compare them; right-click "branch from here" | colour-only branch identity (it is a setting; inference) |
| Figma version history (help.figma.com/hc/en-us/articles/360038006754) | restore is non-destructive (the current state is saved first); named checkpoints; duplicate a version as a new file | a checkpoint every 30 minutes (ours are per round) |
| Notion (notion.com/help/intro-to-databases) | list sorted by newest with runs grouped under their world | nested databases, drag organisation |
| Linear (linear.app/docs/custom-views) | star to pin a favourite; copy a link without granting access | workspace and team scopes |

## Priorities for the page (the agent's)

1. Label each branch in words as well as colour.
2. Make the draft card an explicit approve step (from Replit).
3. Keep restore non-destructive, with a per-round checkpoint (Figma, Smallville forks).
4. Add compare-two-runs (Git Graph, Machinations).
5. Keep the Options block short.
