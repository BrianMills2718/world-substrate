## Why

Brian, 2026-11-16: "i want you to build out the whole ux/ui using best practices and considering designs for simliar projgrams". Increment 4 of `docs/goals/unified-world-ux.md`: branch. Branching existed only as a "Branch from this checkpoint" selector inside Run controls, away from the map.

## What Changes

- A "What if…" button beside the map (owner only) branches the run from the round the map shows, using the existing catalog branch.
- The original run stays on the left; the branch plays live on the right. Round numbers mean the same moment in both.
- When the round cannot be branched the button is greyed with the engine's reason in words.
- This increment is the fallback lever: same start, a new draw. Changing one group's brief is not built.
