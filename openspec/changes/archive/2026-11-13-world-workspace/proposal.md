# World workspace and primary visual scene

Source: Brian, 2026-11-13, requests natural-language creation as the starting page, a persistent list of created worlds, play/replay/branching and an actual spatial/visual world. Follow-up explicitly selects saved-round branching first and defers natural-language interventions and starting-condition configuration.

## Why

The saved-player slice made inspection usable but treated it as the product’s centre. Existing native visual work was fragmented across the composed Coordination Hall, Replay Studio and older generated scenes. The Builder lacks durable logical world/run/checkpoint identity; shares are recordings, not a world library or complete cognitive checkpoints.

## What Changes

Extend the current service/SQLite storage and native continuation path. Keep canonical bundle IDs separate from catalog IDs. Persist owner-created worlds and complete round checkpoints in a private catalog; retain branch parentage and immutable prefixes. Reuse Living Scene v1 projections, the composed renderer, layout and project-owned assets through a generated-world bridge. Do not create a new engine, scheduler, cognition system or renderer.

Home keeps the natural-language creation action with Your worlds below. A world studio puts the visual scene first, with distinct New run, Continue, Replay and Branch from this checkpoint controls and contextual event/actor inspection. Opening/replaying is read-only. Completed-round checkpoints, not material event projections, are the initial branch boundary.

## Failure and compatibility

Catalog acknowledgement fails closed on persistence failure. Stale/duplicate continuation is refused before model work in the deployed single-service process; durable compare-and-swap protects checkpoint ancestry. Public sharing remains explicit. Recovery never invents guest ownership, missing actor memory or legacy parentage. Replay-only histories retain their limitations.

Existing public shares and creation/live routes remain compatible. Spatial geometry is identified as schematic unless canonical coordinates exist. Untrusted world labels remain escaped. Exact actor inputs and Actor-only privacy remain intact.

## Future features

Document, do not implement, natural-language interventions at forks and natural-language configuration of a saved world’s starting conditions. The former applies actions through reviewed mechanics; the latter creates an explicit reviewed initial-state variant. Neither rewrites recorded history or silently assigns beliefs.

## Evidence

Focused catalog/service tests, native scripted-engine continuation/branch tests, retained native spatial scene checks, and one owner-authenticated HTTP/browser journey: create/save or recover an actual world, reopen it, play/replay, preview a completed checkpoint and create an independent branch. Free checks precede any justified provider call; human comprehension and scientific fidelity remain separate.
