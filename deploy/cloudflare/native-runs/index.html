Waltzman demo versions

Every version of the Waltzman coordination demo that exists, side by side. Open each to compare.

1. Cybernetic Influence workbenchcurrent outreach demo

Describe a scenario in plain words, run it fresh, replay and review it. Five worked scenarios, including the 26-agent, four-country case.

How outcomes are decided: an AI referee reads what agents say and judges what happens. Large, rich worlds, but effects are not enforced by rules.

2. Living-world replay (v2)inside version 1

The illustrated "Coordination Hall" scene: a hand-built Waltzman world played back as a blocked baseline and an intervention branch.

How outcomes are decided: World Substrate's rule engine, on a world written by hand.

3. Native World Substrate run (2026-10-08)newest

The Waltzman scenario text turned automatically into rules, then run with AI members. All four of the paper's mechanisms appear as rule events with ids.

Known flaws in this run: its one "deployment blocked" event is invalid (a rule read the wrong counter; fixed since). "Conditional support" and "meetings slowing" are only roughly modelled.

4. World Buildernative authoring tool

Build a world yourself: describe it, get proposed rules, approve them, run it and watch. This is the native path's interactive tool; the run in version 3 came from a newer command-line pipeline not yet in it.

5. Standalone prototyperetired

The earliest synthetic visualization. Kept only as design history; not for showing anyone.
