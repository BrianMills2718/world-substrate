## Why

Brian, 2026-11-16: "i want you to build out the whole ux/ui using best practices and considering designs for simliar projgrams". Increment 7 of `docs/goals/unified-world-ux.md`: the live ten-group walk built a world whose own quick test had gone quiet with every group stalled, and the page went straight to the run without saying so; it also promised "about a minute" for a build that takes two to three.

## What Changes

- When a build goes straight to the run, the run page shows the quick test's warning (the same words the rules review shows) above the run controls.
- The build wait message says the build usually takes two to three minutes.
- On a phone the library list is capped to a third of the screen height and scrolls, so the map stays near the top.
