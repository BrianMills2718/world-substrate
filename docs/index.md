# World Substrate documentation

The reading order for this repository, and a link to every document a reader is meant to open. Read
top to bottom the first time; later, jump to the section you need. Instruction files (`AGENTS.md`)
load for agents without a link and are listed only for completeness.

Last reviewed 2026-11-09 against `main` at `0e66a98` (#345).

## 1. Start here

1. [README](../README.md): what the project is, how to run it, the public World Builder page.
2. [Architecture (arc42)](architecture/arc42.md): goal, requirements, constraints, building blocks,
   runtime, deployment, risks and glossary. This is the architecture entry point; read it before
   changing any system. Its building blocks are drawn in [model.c4](architecture/model.c4).
3. [Project wiki](wiki/README.md): current state in one page, concepts, and what needs resolution.
4. [Roadmap](../roadmap/README.md): stage, active slice, risks and the exact next action.
5. [Lessons](wiki/lessons.md): what would have made earlier work faster. Read before planning.

Agent instructions: [root](../AGENTS.md), [docs](AGENTS.md), [roadmap](../roadmap/AGENTS.md),
[reference worlds](../reference_worlds/AGENTS.md), [tests](../tests/AGENTS.md).
