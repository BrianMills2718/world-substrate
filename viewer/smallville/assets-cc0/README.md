# CC0 art for the public scene viewer

`tinydungeon.png` is the packed tile sheet from Kenney's **Tiny Dungeon** (version 1.0, 16 x 16 px, 12 columns, no spacing), Creative Commons Zero (CC0), by Kenney (www.kenney.nl), downloaded from https://opengameart.org/content/tiny-dungeon (page states CC0; the pack's own `License.txt` is `TinyDungeon-License.txt`). Attribution is not required. Unlike Smallville's art, this may be committed and served publicly.
