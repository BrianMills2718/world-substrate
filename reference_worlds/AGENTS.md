# Reference-world boundary

The root `AGENTS.md` applies.

- A reference world must exercise the shared substrate rather than introduce a private engine.
- World-specific content may define objects, parameters, starting state, and recipes.
- A new mechanism belongs in the shared rule library when another world can use its contract.
- Preserve donor provenance and tests during extraction.
- Until a vertical is reproduced here, its donor repository remains the implementation authority.
- World-specific graphical layout and asset bindings belong in a scene profile; the reusable replay renderer belongs in the shared presentation tooling. Scene geometry is not canonical state unless the world explicitly models coordinates.
