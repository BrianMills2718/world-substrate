# Decision 001: one canonical world-substrate project

Governs: README.md, roadmap/README.md

Source: historical accepted record dated 2026-08-31; its frontmatter names `decision_owner: user`. The original approval quotation is not retained in this file.

## Accepted direction

Create one repository that owns the general world-substrate initiative.

The core outcome is a rich, inspectable world where LLM agents make decisions and executable rules alone determine consequences. Ontologies, transition/process rules, persistence, affordance generation, authoring, and evidence belong to the same coherent project authority.

## Source roles

- Castaway becomes the first reference world and implementation donor.
- Cybernetic Influence V3 is a related product and selective capability donor, not the project container.
- Linguistic Core remains a vocabulary/ontology dependency.
- The Dynamical Laboratory specification informs evaluation and later research.
- Shared `llm_client` remains the model-provider dependency.

Related repositories are not bulk-copied. A capability is migrated only through a named seam and consumer-path proof.

## Non-goals

- recreating Dwarf Fortress;
- a universal real-world ontology or physics engine;
- LLM-generated consequences;
- unrestricted natural-language world mutation;
- merging every related repository into a monorepo;
- claiming predictive accuracy for social or physical systems;
- public deployment or publication at the current stage.

## Later scoped amendments (2026-11-12 reconciliation)
