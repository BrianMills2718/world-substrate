## Adopted versus learned

Only the bounded Castaway fill-through-transfer consumer path has been adopted as implementation. Its evidence remains in the M1 traces and receipts.

The other repositories are idea, theory, contract, or failure donors. Their source code must not be copied merely because a concept is promoted into World Substrate. A narrow pattern may be reimplemented after the relevant World Substrate decision and contract exist.

## Current source findings

- Linguistic Core is the central semantic interface but still requires a coverage audit for persistent state relations, qualities, quantities/units, rights, and institutional relations.
- V3 supplies the strongest canonical intent/proposed-patch/commit boundary reviewed so far, but its current general path does not bind Linguistic Core senses or enforce declared state-path reads/writes at commit.
- V2's one-local-resolver-per-attempt principle is the stronger donor for bounded mechanics authority.
- Agent Ecology 2 demonstrates why permission and contract checks must not commit effects before the enclosing action succeeds.
- Agent Ecology lineages warn against calling installed social policy emergent behavior.
- Collective Competence supplies the anti-double-counting rule: a measured outcome or macro-pattern must not be inserted back as another mechanism.
- Data Contracts supports explicit composition and observability surfaces, not code adoption.

## Current-source cautions

- Donor revisions identify the inspected evidence; later donor changes do not silently change World Substrate doctrine.
- Local paths are conveniences. Revisions and hashes identify source content.
- Worktree changes outside pinned revisions are excluded. Castaway's `world-systems` branch is a linked worktree of `castaway-world`, not a separate repository; both are now pushed to `github.com/BrianMills2718/castaway-world` (private backup), so pinned donor revisions remain recoverable independent of the local checkout.
- A compiler can audit declared dependencies only. It cannot prove that a mechanic author named every consequential dependency.
- Runtime law invention, broad full-world LLM adjudication, and code extraction from the idea donors remain deferred.
