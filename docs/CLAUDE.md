# Documentation boundary

The root `CLAUDE.md` applies. The wiki is derived navigation; architecture, contracts, roadmap, decisions, research synthesis, and source manifests retain their narrower roles.

- Keep what exists, target architecture, gaps, and plans distinct.
- Cite donor revision or content hash for non-obvious imported claims.
- Link native sources instead of copying entire neighboring documentation trees.
- Mark implementation, observed evidence, research input, proposal, and deferred work separately.
- Do not create a handoff document or a second roadmap.
- Run `python scripts/check_project.py` after changing instructions, navigation, plans, or links.
